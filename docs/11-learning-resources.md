## Getting Started Learning Path

### For New Developers
1. **Start with React Fundamentals** (1-2 weeks)
   - Complete the official React tutorial
   - Understand hooks and component patterns
   - Practice with small projects

2. **Learn the UI Framework** (1 week)
   - Explore shadcn/ui components
   - Understand Tailwind CSS utility classes
   - Practice building interfaces

3. **Understand State Management** (1 week)
   - Learn React Context API
   - Understand TanStack Query concepts
   - Practice with data fetching patterns

4. **Backend Basics** (1-2 weeks)
   - Learn Flask fundamentals
   - Understand REST API concepts
   - Practice with Python development

5. **Project-Specific Concepts** (1-2 weeks)
   - Study the AI integration patterns
   - Understand the processing pipeline
   - Learn about TTS and audio processing

### For Experienced Developers
1. **Project Architecture Review** (2-3 days)
   - Study the system architecture documentation
   - Understand the data flow patterns
   - Review the API documentation

2. **Technology-Specific Learning** (1 week)
   - Focus on unfamiliar technologies (LiteLLM, Kokoro TTS, etc.)
   - Understand the integration patterns
   - Review the configuration management

3. **Hands-On Exploration** (1 week)
   - Set up the development environment
   - Run through the user flows
   - Experiment with modifications
